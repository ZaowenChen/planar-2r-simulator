# 界面符号表

本表覆盖应用公式、参数编辑器、矩阵、结果与实验曲线中显示的数学符号。角度输入可在运动学面板切换为度，但内部计算和下表默认单位均为弧度。

| 符号 | 中文含义 | SI 单位 |
|---|---|---|
| $i,j,k$ | 连杆、关节或矩阵索引 | 1（无量纲） |
| $\{0\},\{1\},\{2\},\{3\},\{e\}$ | 基座、各连杆与末端坐标系 | 1 |
| $q=[\theta_1,\theta_2,\theta_3]^T$ | 关节位置向量 | rad |
| $\dot q,\ddot q$ | 关节速度、关节加速度 | rad/s，rad/s² |
| $q_d,\dot q_d,\ddot q_d$ | 期望关节轨迹及一、二阶导数 | rad，rad/s，rad/s² |
| $\theta_i$ | 第 $i$ 个转动关节角 | rad |
| $d_i,a_i,\alpha_i$ | 标准 D–H 偏距、杆长、扭角 | m，m，rad |
| $d_1$ | 基座高度 | m |
| $l_2,l_3$ | 第二、第三连杆长度 | m |
| ${}^{i-1}T_i,{}^0T_3$ | 相邻坐标系、基座到第三连杆的齐次变换 | 1 |
| ${}^0R_i$ | 连杆 $i$ 到基坐标系的旋转矩阵 | 1 |
| ${}^0p_e$ | 末端在基坐标系中的位置 | m |
| ${}^0p_d=[x,y,z]^T$ | 期望末端位置 | m |
| ${}^0p_{c_i}$，$c_i$ | 第 $i$ 连杆质心位置、质心标记 | m |
| $r,z',D$ | IK 径向距离、相对高度、余弦中间量 | m，m，1 |
| $J,J_v,J_\omega$ | 几何、线速度、角速度雅可比 | 混合；m/rad 与 1/rad |
| ${}^0v_e,{}^0\omega_e$ | 末端线速度、角速度 | m/s，rad/s |
| $\sigma_{\min},\sigma_{\max}$ | 位置雅可比最小、最大奇异值 | m/rad |
| $\kappa$ | 位置雅可比或惯性矩阵条件数 | 1 |
| $m_i$ | 第 $i$ 连杆质量 | kg |
| ${}^{c_i}I_i$ | 第 $i$ 连杆绕质心的惯量张量 | kg·m² |
| $M(q)$ | 关节空间惯性矩阵 | kg·m² |
| $c_{ijk}$ | 第一类 Christoffel 系数 | kg·m²/rad |
| $C(q,\dot q)$ | 科氏/离心矩阵 | kg·m²/s |
| ${}^0g=[g_x,g_y,g_z]^T$ | 基坐标系重力加速度 | m/s² |
| $g(q)$ | 广义重力力矩向量 | N·m |
| $b_i,B$ | 关节粘性摩擦系数及对角矩阵 | N·m·s/rad |
| $\tau=[\tau_1,\tau_2,\tau_3]^T$ | 关节驱动力矩 | N·m |
| $\tau_f=B\dot q$ | 粘性摩擦力矩 | N·m |
| $K,V,E$ | 动能、势能、总机械能 | J |
| $P_i=\tau_i\dot q_i$ | 第 $i$ 关节功率 | W |
| $t,T,h$ | 仿真时刻、持续时间、积分/差分步长 | s，s，s（质量偏导的 $h$ 为 rad） |
| $q_0,q_f$ | 五次轨迹起始、终止关节位置 | rad |
| $u=t/T,s(u)$ | 归一化时间、五次平滑函数 | 1 |
| $\bar q_i,A_i,f_i,\phi_i$ | 正弦轨迹中心、振幅、频率、相位 | rad，rad，Hz，rad |
| $k_1,k_2,k_3,k_4$ | RK4 四个状态斜率 | 状态单位/s |
