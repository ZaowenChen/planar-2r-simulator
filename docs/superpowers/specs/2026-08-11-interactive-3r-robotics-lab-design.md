# 空间 3R 机器人学交互实验室设计

## 1. 目标

将现有 Python/Matplotlib 空间 3R 机械臂可视化升级为面向浏览器的中文机器人学交互实验室。应用以现有偏航–俯仰–俯仰 3R 机械臂为唯一研究对象，把刚体变换、正逆运动学、速度运动学、雅可比奇异性、完整刚体动力学、轨迹与时间仿真组织成一条可验证的学习路径。

用户修改姿态、末端目标、轨迹、力矩或物理参数后，3D 模型、数学公式中的当前值、矩阵结果、状态曲线和能量曲线必须同步更新。应用使用中文讲解和国际标准数学符号，不在界面中暴露源码式变量名。

## 2. 产品边界

### 2.1 包含范围

- 空间 3R 偏航–俯仰–俯仰机械臂的交互式 3D 模型。
- 标准 D–H 正运动学、闭式位置逆运动学及多解。
- 末端线速度与角速度雅可比、奇异值和条件数。
- 带可编辑刚体参数、重力与黏性摩擦的完整动力学。
- 逆动力学轨迹实验和正动力学力矩实验。
- 关节状态、力矩、能量和功率时间曲线。
- 公式的定义、当前参数代入和数值结果三层展示。
- 参数校验、数值异常提示、CSV 导出和图表导出。
- 中文 README、数学模型说明、符号表、自动测试和 GitHub Pages。

### 2.2 不包含范围

- 不增加其他机械臂模型或通用 URDF 导入。
- 不增加反馈控制器、路径规划、碰撞检测或接触动力学。
- 不增加登录、数据库、云端计算或 Python 服务端。
- 不在线执行任意用户代码或任意数学表达式。
- 不要求移动端完成高密度实验操作；移动端只需能阅读，主要交互面向桌面浏览器。

## 3. 机械臂定义

机械臂沿用现有空间 3R 模型：

- 关节 1 绕基坐标系的 Z 轴偏航，变量为 \(\theta_1\)。
- 关节 2 为肩部俯仰，变量为 \(\theta_2\)。
- 关节 3 为肘部俯仰，变量为 \(\theta_3\)。
- 基座高度为 \(d_1\)，上臂长度为 \(L_2\)，前臂长度为 \(L_3\)。
- 默认工具变换 \(^{3}\mathbf T_e=\mathbf I_4\)。

标准 D–H 表为：

| 关节 \(i\) | \(a_{i-1}\) | \(\alpha_{i-1}\) | \(d_i\) | \(\theta_i\) |
| --- | ---: | ---: | ---: | ---: |
| 1 | \(0\) | \(+\pi/2\) | \(d_1\) | \(\theta_1\) |
| 2 | \(L_2\) | \(0\) | \(0\) | \(\theta_2\) |
| 3 | \(L_3\) | \(0\) | \(0\) | \(\theta_3\) |

默认几何参数为 \(d_1=0.8\,\mathrm m\)、\(L_2=2.0\,\mathrm m\)、\(L_3=1.5\,\mathrm m\)。默认关节范围为 \(\theta_1\in[-180^\circ,180^\circ]\)、\(\theta_2\in[-90^\circ,90^\circ]\)、\(\theta_3\in[-150^\circ,150^\circ]\)。内部计算统一使用弧度。

每根连杆 \(i\) 具有可编辑质量 \(m_i\)、在连杆坐标系表达的质心位置 \(^{i}\mathbf r_{c_i}\) 以及相对质心、平行于连杆坐标轴表达的惯量张量 \(^{c_i}\mathbf I_i\)。惯量编辑器提供六个独立对称分量，显示时重建完整 \(3\times3\) 矩阵。重力向量默认为 \(^{0}\mathbf g=[0,0,-9.81]^{\mathsf T}\,\mathrm{m/s^2}\)。黏性摩擦使用可编辑的非负对角矩阵 \(\mathbf B\)，并允许整体关闭。

默认刚体参数为：

| 连杆 | \(m_i\)（kg） | \(^{i}\mathbf r_{c_i}\)（m） | \(^{c_i}\mathbf I_i\)（kg·m²） |
| --- | ---: | --- | --- |
| 1 | 4.0 | \([0,-0.4,0]^{\mathsf T}\) | \(\operatorname{diag}(0.2133,0.0200,0.2133)\) |
| 2 | 3.0 | \([-1.0,0,0]^{\mathsf T}\) | \(\operatorname{diag}(0.0300,1.0000,1.0000)\) |
| 3 | 2.0 | \([-0.75,0,0]^{\mathsf T}\) | \(\operatorname{diag}(0.0200,0.3750,0.3750)\) |

默认黏性摩擦为 \(\mathbf B=\operatorname{diag}(0.08,0.08,0.05)\,\mathrm{N\,m\,s/rad}\)。这些值是可复现实验用的教学参数，不宣称对应某个商业机械臂。

## 4. 符号与显示规范

界面统一采用论文式 LaTeX：

- 关节状态为 \(\mathbf q=[\theta_1,\theta_2,\theta_3]^{\mathsf T}\)、\(\dot{\mathbf q}\)、\(\ddot{\mathbf q}\)。
- 关节力矩为 \(\boldsymbol\tau=[\tau_1,\tau_2,\tau_3]^{\mathsf T}\)。
- 坐标系写作 \(\{0\},\{1\},\{2\},\{3\},\{e\}\)。
- 从坐标系 \(i\) 到坐标系 \(0\) 的变换写作 \(^{0}\mathbf T_i\)。
- 末端位置写作 \(^{0}\mathbf p_e\)，期望位置写作 \(^{0}\mathbf p_d\)。
- 旋转矩阵、雅可比、惯性矩阵和科氏矩阵使用粗体大写；向量使用粗体小写或公认的希腊粗体。
- 每个量在首次出现处给出中文名称、定义和 SI 单位。

界面禁止显示 `x_target`、`P_B^T`、`T_0^3`、`a_(i-1)` 等源码式文本。代码中的内部变量不受此限制，但所有用户可见复制文本、图例、控件、表头、状态提示和导出表头必须经过显示层映射。

公式卡片固定提供三个视图：

1. “定义”显示标准符号公式和符号释义。
2. “代入”把当前几何、物理和状态值代入同一公式。
3. “结果”显示带单位的实时标量、向量或矩阵。

显示角度允许在度和弧度之间切换，计算值和 CSV 数据保留 SI 制及弧度，并在表头中注明单位。

## 5. 数学模型

### 5.1 坐标变换与正运动学

单节标准 D–H 变换为

\[
^{i-1}\mathbf T_i
=
\mathbf R_z(\theta_i)\mathbf T_z(d_i)
\mathbf T_x(a_{i-1})\mathbf R_x(\alpha_{i-1}).
\]

末端变换为

\[
^{0}\mathbf T_e(\mathbf q)
=
^{0}\mathbf T_1(\theta_1)
^{1}\mathbf T_2(\theta_2)
^{2}\mathbf T_3(\theta_3)
^{3}\mathbf T_e.
\]

界面显示变换链、当前齐次矩阵、末端位置和姿态。3D 视图显示每个关节坐标系和末端坐标系。

### 5.2 闭式逆运动学

对期望位置 \(^{0}\mathbf p_d=[x_d,y_d,z_d]^{\mathsf T}\)，定义

\[
r=\sqrt{x_d^2+y_d^2},\qquad
z'=z_d-d_1,\qquad
D=\frac{r^2+z'^2-L_2^2-L_3^2}{2L_2L_3}.
\]

当 \(|D|\le 1\) 时计算肘上和肘下两组解；边界处允许两解重合。目标不可达、位于基座轴线或解超出关节限位时，界面给出独立状态，不覆盖最后一个有效姿态。

### 5.3 速度运动学与奇异性

末端扭量满足

\[
^{0}\mathbf V_e=
\begin{bmatrix}
^{0}\mathbf v_e\\
^{0}\boldsymbol\omega_e
\end{bmatrix}
=\mathbf J(\mathbf q)\dot{\mathbf q}.
\]

应用分别展示线速度雅可比 \(\mathbf J_v\)、角速度雅可比 \(\mathbf J_\omega\)、奇异值、最小奇异值和条件数。最小奇异值低于警戒阈值时，视图和公式卡片同时高亮；默认阈值为 \(10^{-3}\)，允许在 \(10^{-8}\) 至 \(10^{-1}\) 之间设置。条件数无穷大时显示“奇异”，不显示误导性的有限数值。

### 5.4 刚体动力学

完整模型为

\[
\boldsymbol\tau
=\mathbf M(\mathbf q)\ddot{\mathbf q}
+\mathbf C(\mathbf q,\dot{\mathbf q})\dot{\mathbf q}
+\mathbf g(\mathbf q)
+\mathbf B\dot{\mathbf q}.
\]

惯性矩阵由各连杆质心雅可比构造：

\[
\mathbf M(\mathbf q)
=\sum_{i=1}^{3}
\left(
m_i\mathbf J_{v_i}^{\mathsf T}\mathbf J_{v_i}
+\mathbf J_{\omega_i}^{\mathsf T}
\,^{0}\mathbf R_i\,^{c_i}\mathbf I_i\,^{0}\mathbf R_i^{\mathsf T}
\mathbf J_{\omega_i}
\right).
\]

科氏矩阵采用第一类 Christoffel 符号定义：

\[
c_{ijk}
=\frac12\left(
\frac{\partial M_{ij}}{\partial q_k}
+\frac{\partial M_{ik}}{\partial q_j}
-\frac{\partial M_{jk}}{\partial q_i}
\right),\qquad
C_{ij}=\sum_{k=1}^{3}c_{ijk}\dot q_k.
\]

应用用中心差分计算 \(\partial\mathbf M/\partial q_k\)，默认差分步长为 \(10^{-5}\,\mathrm{rad}\)，并在模型说明中明确标注“Christoffel 精确定义、中心差分数值求值”。总势能及其重力项为：

\[
V(\mathbf q)=-\sum_{i=1}^{3}m_i\,^{0}\mathbf g^{\mathsf T}\,^{0}\mathbf p_{c_i}(\mathbf q),
\qquad
\mathbf g(\mathbf q)=\frac{\partial V(\mathbf q)}{\partial\mathbf q}
=-\sum_{i=1}^{3}m_i\mathbf J_{v_i}^{\mathsf T}\,^{0}\mathbf g.
\]

动能、势能、总机械能和单关节功率为

\[
K=\frac12\dot{\mathbf q}^{\mathsf T}\mathbf M\dot{\mathbf q},\qquad
E=K+V,\qquad
P_i=\tau_i\dot q_i.
\]

## 6. 动态实验

### 6.1 逆动力学实验

输入为期望关节轨迹 \(\mathbf q_d(t)\)，输出为所需关节力矩。内置两类轨迹：

- 五次多项式点到点轨迹：编辑初始关节位置、目标关节位置和持续时间，默认端点速度与加速度为零。
- 正弦轨迹：编辑中心位置、振幅、频率和相位。

轨迹生成器同时返回 \(\mathbf q_d\)、\(\dot{\mathbf q}_d\) 和 \(\ddot{\mathbf q}_d\)，再由完整动力学方程计算 \(\boldsymbol\tau_d\)。

### 6.2 正动力学实验

输入为关节力矩 \(\boldsymbol\tau(t)\)，输出为 \(\mathbf q(t)\)、\(\dot{\mathbf q}(t)\) 和 \(\ddot{\mathbf q}(t)\)：

\[
\ddot{\mathbf q}
=\mathbf M(\mathbf q)^{-1}
\left[
\boldsymbol\tau
-\mathbf C(\mathbf q,\dot{\mathbf q})\dot{\mathbf q}
-\mathbf g(\mathbf q)
-\mathbf B\dot{\mathbf q}
\right].
\]

力矩输入支持常值、阶跃、正弦和分段常值，不执行任意表达式。状态使用固定步长四阶 Runge–Kutta 法积分，默认仿真步长为 \(0.005\,\mathrm s\)，允许在 \(0.001\) 至 \(0.02\,\mathrm s\) 内设置。绘制刷新频率与物理积分步长分离。

两种实验都提供播放、暂停、单步、重置、仿真速度和持续时间。动画时间、曲线游标、3D 姿态与公式数值使用同一个仿真时刻。

## 7. 信息架构与界面

应用包含四个顶层模块：

1. “机器人模型”：几何、刚体参数、环境、坐标系和标准 D–H 表。
2. “运动学”：正运动学、逆运动学、雅可比、奇异性和工作空间。
3. “动力学”：\(\mathbf M\)、\(\mathbf C\)、\(\mathbf g\)、摩擦、能量和功率。
4. “动态实验”：逆动力学轨迹实验和正动力学力矩实验。

每个模块采用一致的三栏工作台：

- 左侧为 3D 视图。
- 中间为当前模块的输入与控制。
- 右侧为公式、符号解释和实时数值。
- 下方按需展开共享时间轴曲线。

3D 视图支持旋转、缩放和视角复位，并可开关局部坐标系、质心、工作空间、末端轨迹、速度、加速度、重力和力矩矢量。选择公式项、关节或连杆时，其关联对象同步高亮。

曲线包含 \(\mathbf q\)、\(\dot{\mathbf q}\)、\(\ddot{\mathbf q}\)、\(\boldsymbol\tau\)、\(K\)、\(V\)、\(E\) 和 \(P_i\)。共享游标既能随动画前进，也能由用户拖动并反向定位三维姿态。结果可导出 CSV；图表可保存为 SVG 或 PNG。

## 8. 状态与数据流

应用采用单向状态流：

\[
\text{用户输入}
\rightarrow\text{参数验证}
\rightarrow\text{机器人学计算核心}
\rightarrow\text{统一实验状态}
\rightarrow\text{3D、公式与曲线渲染}.
\]

机器人学核心由无 React 依赖的纯 TypeScript 函数组成。同一个计算结果对象同时提供给 3D、公式卡和图表，禁止各组件重复计算并产生不一致数值。动画时钟是仿真时间的唯一来源。重置操作恢复经过验证的默认参数和初始状态。

## 9. 工程架构

采用以下技术栈：

- Vite、React 和 TypeScript 构建静态单页应用。
- Three.js 与 React Three Fiber 渲染 3D 场景。
- KaTeX 渲染数学公式。
- Plotly 绘制同步时间曲线。
- Zustand 保存统一实验状态。
- Vitest、React Testing Library 和 Playwright 完成自动验证。
- GitHub Actions 执行测试和构建，GitHub Pages 托管静态产物。

核心目录按责任划分：

```text
src/robotics/
├── transforms       坐标变换与标准 D–H
├── kinematics       正逆运动学
├── jacobian         速度映射与奇异性
├── dynamics         M、C、g、能量和功率
├── trajectories     五次多项式与正弦轨迹
├── integration      RK4 与正动力学状态方程
├── validation       几何、刚体和数值校验
└── types            参数、状态与结果类型
```

页面组件、3D 场景、公式卡、图表、状态存储和导出工具各自位于独立目录。现有 Python 2R 与 3R 程序保存到 `legacy/`，作为迁移参考和独立数值对照，不再作为主入口。

## 10. 输入验证与故障处理

- 连杆长度和质量必须为有限正数；基座高度必须为有限非负数。
- 惯量张量必须有限、对称；最小特征值必须大于 \(10^{-9}\,\mathrm{kg\,m^2}\)，三个主惯量在 \(10^{-9}\) 容差内满足任一主惯量不大于另外两个之和。
- 质心向量必须有限，并满足 \(\lVert^{i}\mathbf r_{c_i}\rVert_2\le \ell_i\)，其中 \((\ell_1,\ell_2,\ell_3)=(d_1,L_2,L_3)\)；越界时给出对应连杆和向量范数。
- 黏性摩擦系数必须有限且非负。
- 所有输入必须能转换为有限 SI 数值。
- 逆运动学不可达或超限时保留最后一个有效姿态。
- 接近奇异位形时显示最小奇异值和条件数，不阻断纯运动学观察。
- 惯性矩阵最小特征值不大于 \(10^{-9}\) 或条件数超过 \(10^{10}\) 时，阻止开始正动力学实验。
- 积分状态出现非有限值，或任一关节超出第 3 节定义的关节范围时自动暂停，保留可检查的最后有效样本；关节限位不通过数值裁剪或隐式力矩掩盖。
- 错误信息必须指出对应参数或数学条件，不使用笼统的“计算失败”。

## 11. 测试与验收

### 11.1 数学核心

- 单节 D–H 变换和完整变换链与手算参考一致。
- 旋转矩阵保持正交且行列式为 \(+1\)。
- 闭式逆运动学的两组有效解经正运动学返回目标点。
- 几何雅可比与末端位姿的中心差分一致。
- 惯性矩阵在有效参数范围内对称正定。
- 数值计算满足 \(\dot{\mathbf M}-2\mathbf C\) 的反对称性质，测试要求其对称残差 Frobenius 范数小于 \(10^{-6}\)。
- 逆动力学力矩代入正动力学后恢复给定加速度。
- 无输入、无摩擦、步长 \(0.001\,\mathrm s\) 的两秒仿真中，总机械能相对漂移不超过 \(0.5\%\)。
- RK4 对已知平滑测试问题表现出四阶收敛趋势；连续两次将步长减半时，终值误差比至少为 12。
- 五次多项式轨迹满足端点位置、速度和加速度约束。

### 11.2 界面与集成

- 所有可见符号使用本规格定义的显示形式，不泄漏源码变量名。
- 改变任一关节后，3D、变换、雅可比和动力学结果使用同一状态。
- 改变刚体参数后，运动学不变而动力学结果更新。
- 逆动力学与正动力学能完成播放、暂停、单步、重置和时间定位。
- 公式“定义、代入、结果”三层数值一致。
- 奇异、不可达、无效惯量和积分发散状态具有可辨识提示。
- CSV 字段、单位和时间样本正确；SVG/PNG 导出可用。
- Chrome 中完成一条端到端实验流程并保存视觉验收截图。
