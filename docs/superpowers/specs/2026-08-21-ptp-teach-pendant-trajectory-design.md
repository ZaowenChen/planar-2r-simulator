# PTP 示教与轨迹生成实验室设计

## 1. 目标

把现有“动态实验”页面改造成不介入动力学的“PTP 示教与轨迹生成实验室”。界面模拟真实机器人示教器的核心工作流，让学习者通过关节点动、记录示教点、创建 PTP 指令、生成关节轨迹和 3D 试运行，理解轨迹生成的输入、数学过程和运动结果。

第一版的教学主线为：

```text
JOG 当前姿态
→ 记录 P1、P2 示教点
→ 创建 PTP(P1, P2, 轨迹类型, 持续时间)
→ 生成 q(t)、q̇(t)、q̈(t)
→ 同步观察公式、曲线和 3D 运动
```

成功标准是学习者能解释：起终关节角和持续时间如何决定关节位置、速度与加速度曲线；五次多项式和梯形速度轨迹有什么区别；为什么缩短持续时间会提高速度与加速度峰值。

## 2. 范围

### 2.1 包含范围

- 三关节 JOG 点动，支持 `0.1°`、`1°` 和 `5°` 步长。
- 记录、重命名、更新和删除会话内示教点，默认自动命名为 P1、P2、P3 等。
- 从两个示教点创建一条关节空间 PTP 指令。
- 五次多项式和梯形速度两类同步点到点轨迹。
- 五次多项式的边界条件、归一化时间、插值函数及当前时刻代入教学。
- 梯形速度的加速、匀速、减速分段教学。
- 归一化插值曲线与三关节 `q`、`q̇`、`q̈` 曲线。
- 大尺寸 3D 场景、示教点、末端运动路径和同步时间游标。
- 播放、暂停、单步、复位、播放倍率、拖动时间和独立放大 3D。
- 关节限位、持续时间、有限数值、端点误差和轨迹完整性校验。
- 峰值速度、峰值加速度、持续时间和端点误差摘要。
- 轨迹 CSV 以及曲线 SVG/PNG 导出沿用现有导出能力，字段只包含时间和关节状态。

### 2.2 不包含范围

- 不计算惯性矩阵、科氏项、重力项、关节力矩、能量或功率。
- 不提供正动力学、逆动力学或力矩输入实验。
- 不提供笛卡尔直线 LIN、圆弧 CIRC、样条路径或连续多段程序。
- 不提供速度规划器的任意平台速度、加速时间或逐轴速度参数。
- 不使用正弦轨迹作为 PTP 类型；已有正弦数学实现保留，但不出现在第一版示教器中。
- 不模拟真实示教器的安全回路、使能开关、急停、碰撞或工业控制权限。
- 示教点和指令第一版只保存在当前浏览器会话状态中，刷新或“重置实验室”后清除，不使用数据库或持久化程序文件。

## 3. 现有实现的复用与调整

不推翻现有项目。采用局部模块化重构：

### 3.1 直接复用

- `src/robotics/trajectories.ts` 中的五次多项式、梯形速度与单时刻求值函数。
- `RobotScene`、正运动学、关节状态和现有 3D 相机交互。
- `WorkbenchLayout` 的工作台结构和应用视觉语言。
- Zustand 中的机器人参数与当前关节角可作为进入页面时的初始姿态；轨迹页面沿用仿真时间、播放状态和播放倍率的交互概念。
- Plotly 图表、图表点击定位和 SVG/PNG 导出基础设施。
- CSV 下载基础设施。

### 3.2 定向重构

- 当前 `ExperimentPage` 同时处理正/逆动力学、配置解析、仿真、公式和播放，改为由新的轨迹教学页面组织纯轨迹数据。
- 当前 `SimulationControls` 替换为示教器、示教点列表和 PTP 指令编辑器。
- 当前 `TimeSeriesCharts` 依赖动力学 `SimulationSample`，新建只依赖轨迹样本的 `TrajectoryCharts`，不在原组件中堆叠条件分支。
- 当前动画时钟依赖动力学样本，改为只依赖持续时间和播放状态的通用时间控制；当前轨迹值直接按连续时间解析求值。
- 轨迹页面使用独立的会话状态保存 JOG 姿态、示教点、指令草稿和播放姿态，不在每个动画帧调用现有 `setJointVector`，避免触发现有全局计算对象中的动力学计算。
- 3D 场景由当前轨迹 `q`、机器人参数、正运动学和几何雅可比构造纯运动学视图模型，不传入力矩、重力或动力学结果。
- “动态实验”导航和页面标题改为“轨迹示教”；独立的“动力学”模块保持不变。

## 4. 用户体验与信息架构

### 4.1 桌面布局

顶部工作区采用约 `50% / 27% / 23%` 的三栏比例：

1. 左侧为大尺寸 3D 机器人示教与试运行场景。
2. 中间为虚拟示教器、示教点和 PTP 指令。
3. 右侧为数学教学步骤、公式和当前时刻代入。

顶部工作区目标高度为 `590–680 px`，其中 3D 画布目标高度为 `520–600 px`。3D 栏提供“放大 3D”按钮，进入只扩大场景的展示模式；退出后恢复三栏布局，播放时间和当前轨迹不重置。

底部横跨全宽展示两类同步图表：

- 左侧为归一化插值函数 `s(u)`、`s'(u)`、`s''(u)`。
- 右侧为三关节 `q(t)`、`q̇(t)`、`q̈(t)`，使用页签切换状态量。

两组图表共享当前时刻竖直游标。图表点击、时间滑块、公式代入和 3D 姿态使用同一个时间状态。

### 4.2 响应式布局

- 宽屏：保持三栏和大尺寸 3D。
- 中等宽度：3D 与示教器留在第一行，数学栏移到第二行并与图表相邻。
- 窄屏：按“3D → 示教器 → 数学 → 图表”纵向排列；主要操作面向桌面，窄屏保证阅读和基础试运行。

### 4.3 渐进式教学链

界面用四个编号步骤组织内容，但不使用割裂现有工作台的全屏向导：

1. **定义姿态**：JOG 三个关节并记录示教点。
2. **建立指令**：选择起点、终点、轨迹类型和持续时间。
3. **看懂生成过程**：展示边界条件、归一化时间和插值公式。
4. **预览并试运行**：观察曲线、峰值和 3D 运动。

已经完成的步骤保持可见；高级用户可以直接展开全部内容。

## 5. 组件边界

建议新增 `src/features/trajectory/`：

```text
src/features/trajectory/
├── TrajectoryTeachingPage.tsx    页面组织和共享状态接线
├── TeachPendantPanel.tsx         JOG、步长与模式提示
├── TeachPointList.tsx            示教点记录与管理
├── PtpInstructionEditor.tsx      起终点、类型和持续时间
├── PolynomialLesson.tsx          五次多项式教学
├── TrapezoidalLesson.tsx         梯形速度分段教学
├── TrajectoryCharts.tsx          s / q / q̇ / q̈ 图表
├── TrajectoryPlayback.tsx        播放与时间定位
├── trajectoryStore.ts            独立的示教与播放会话状态
├── trajectoryModel.ts            草稿、校验、采样与指标
└── trajectoryModel.test.ts       页面无关的教学模型测试
```

每个组件只接收其所需数据和回调。轨迹数学、校验和指标不写在 React 组件内部；组件不重复生成轨迹。

## 6. 数据模型与状态

```ts
interface TeachPoint {
  id: string
  name: string
  q: Vector3
}

type PtpProfile = 'quintic' | 'trapezoidal'

interface PtpInstructionDraft {
  startPointId: string
  endPointId: string
  profile: PtpProfile
  durationText: string
}

interface PtpInstruction {
  startPointId: string
  endPointId: string
  q0: Vector3
  qf: Vector3
  profile: PtpProfile
  duration: number
}

interface TimedTrajectorySample {
  time: number
  q: Vector3
  qd: Vector3
  qdd: Vector3
}

interface TrajectoryMetrics {
  peakVelocity: Vector3
  peakAcceleration: Vector3
  startError: Vector3
  endError: Vector3
}

interface TrajectoryPreview {
  instruction: PtpInstruction
  samples: readonly TimedTrajectorySample[]
  metrics: TrajectoryMetrics
}
```

内部 `Vector3` 继续使用弧度、弧度每秒和弧度每二次方秒。界面编辑、标签、教学结果和默认曲线使用度制；转换只发生在显示和输入边界，CSV 保持弧度并在表头注明单位。

轨迹模块使用独立的 Zustand `trajectoryStore`，不把播放姿态写入现有 `labStore.calculation`。它在模块切换期间保留示教点和指令，但不接入 `localStorage`；刷新页面或执行“重置实验室”会清除轨迹会话并恢复默认状态。

示教点的 `q` 在记录时复制，后续 JOG 或播放不得修改已保存数组。编辑示教点名称不触发轨迹重算；更新点位、删除被引用点位、改变轨迹类型或改变持续时间会暂停播放、把时间复位为零并重新生成有效预览。

第一次选择有效起终点后，用户点击“生成轨迹预览”建立 PTP 指令，强化“示教点 → 指令 → 轨迹”的因果关系。预览建立以后，修改有效点位、轨迹类型或持续时间会即时更新 `q`、`q̇`、`q̈`、公式和峰值，不要求重复点击按钮；无效草稿不替换最后一次有效预览。

## 7. 数据流

```text
JOG 输入
  → 关节限位校验
  → 更新轨迹会话当前 q
  → 3D 即时更新

记录示教点
  → 复制当前 q
  → TeachPoint[]

示教点 + PTP 草稿
  → 解析与校验
  → TrajectoryConfig
  → 轨迹批量采样 + 指标
  → TrajectoryPreview

连续播放时间 t
  → evaluateTrajectory(config, t)
  ├→ 当前 q 写入 3D
  ├→ 当前 q / q̇ / q̈ 数值
  ├→ 当前公式代入
  └→ 两组图表共享游标
```

图表预览使用包含首尾端点的 `201` 个等间隔样本。3D 播放和当前公式不依赖最近样本，而是使用当前连续时间直接调用解析轨迹函数，避免低采样率造成机械臂跳动。单步按照预览样本间隔移动。

轨迹页面只从全局实验室读取机器人参数、关节限位和进入页面时的初始关节角。JOG、预览和播放都留在轨迹会话内；不会调用 `simulateInverseDynamics`、`simulateForwardDynamics`、`inverseDynamics` 或动力学积分函数。

## 8. 数学教学

### 8.1 五次多项式

定义归一化时间

\[
u=\frac{t}{T},\qquad 0\le u\le1.
\]

边界条件为

\[
s(0)=0,\ s(1)=1,\quad
s'(0)=s'(1)=0,\quad
s''(0)=s''(1)=0.
\]

插值函数及其对归一化时间的导数为

\[
s(u)=10u^3-15u^4+6u^5,
\]

\[
s'(u)=30u^2-60u^3+30u^4,
\qquad
s''(u)=60u-180u^2+120u^3.
\]

对每个关节定义 \(\Delta q_i=q_{i,f}-q_{i,0}\)，得到

\[
q_i(t)=q_{i,0}+\Delta q_i s(u),
\]

\[
\dot q_i(t)=\frac{\Delta q_i}{T}s'(u),
\qquad
\ddot q_i(t)=\frac{\Delta q_i}{T^2}s''(u).
\]

教学界面按“定义 → 当前参数代入 → 数值结果”展示，并解释持续时间缩放：轨迹几何形状不变，速度按 `1/T`、加速度按 `1/T²` 缩放。

峰值指标使用解析结果而不是从 `201` 个绘图样本估计：

\[
\max |\dot q_i|=\frac{1.875|\Delta q_i|}{T},
\qquad
\max |\ddot q_i|=\frac{10|\Delta q_i|}{\sqrt3T^2}.
\]

### 8.2 梯形速度

第一版沿用现有同步轨迹定义：加速、匀速和减速各占总持续时间的三分之一，归一化平台速度为 `1.5`，归一化加速度为 `4.5`。

\[
s(u)=
\begin{cases}
2.25u^2,&0\le u\le\frac13,\\
1.5u-0.25,&\frac13<u\le\frac23,\\
1-2.25(1-u)^2,&\frac23<u\le1.
\end{cases}
\]

界面为三个时间区间着色，并明确说明：位置与速度连续，加速度在分段边界跳变；这是该轨迹的数学特征，不是数值错误。

梯形速度的峰值同样使用解析结果：

\[
\max |\dot q_i|=\frac{1.5|\Delta q_i|}{T},
\qquad
\max |\ddot q_i|=\frac{4.5|\Delta q_i|}{T^2}.
\]

## 9. 校验与故障处理

生成预览前依次检查：

- 起点和终点均引用存在的示教点。
- 起点和终点关节向量不同；完全相同时提示“没有需要执行的 PTP 位移”。
- 三个关节端点均处于机器人参数给定的关节限位内。
- 持续时间为有限数值且位于 `0.1–30 s`。
- 轨迹类型为第一版允许的五次多项式或梯形速度。
- 生成样本的时间、位置、速度和加速度全部有限。
- 首尾位置误差不超过 `1e-10 rad`；首尾速度不超过 `1e-10 rad/s`。

状态分级为：

- **有效**：即时更新轨迹和指标。
- **提示**：持续时间缩短导致峰值增大，但在没有额定速度和加速度参数时不宣称安全或危险。
- **教学说明**：例如梯形速度的加速度分段跳变，不阻断播放。
- **阻断错误**：引用点缺失、端点超限、时间无效或样本非有限。停止播放并保留最后一次有效预览，避免无效草稿覆盖可检查结果。

删除正在被 PTP 指令引用的示教点时，要求一次明确确认；删除后清空对应引用并停止播放。普通 JOG 在到达限位后停止增加或减少，并在对应关节行给出限位提示。

## 10. 测试设计

### 10.1 数学核心

- 五次多项式满足起终位置、速度和加速度边界条件。
- 五次多项式解析速度和加速度与位置函数的中心差分一致。
- 持续时间乘以 `k` 后，相同归一化时刻的位置不变，速度缩放为 `1/k`，加速度缩放为 `1/k²`。
- 梯形速度正确经过三个分段，位置和速度在分界处连续，加速度具有预期跳变。
- 正向与负向关节位移均正确，三个关节同步到达终点。
- `201` 点采样包含精确起点、精确终点和严格单调时间。
- 峰值、端点误差、度/弧度转换与关节限位判断正确。

### 10.2 组件与状态

- JOG 只改变目标关节，并采用选定步长。
- JOG 到达限位后停止并显示对应提示。
- 记录示教点会复制当前关节向量；后续 JOG、播放或复位不改变已保存点位。
- 重命名点位不重算轨迹，更新点位会暂停并重新生成预览。
- 删除被引用点位需要确认，并清空失效引用。
- 无效草稿不会覆盖最后一次有效预览。
- 播放、暂停、单步、复位、倍率和时间定位使用同一个时间状态。
- 当前公式、3D 姿态和曲线游标在同一时间点显示一致数值。
- 放大和退出 3D 不改变播放时间或轨迹配置。
- JOG 和播放不调用动力学仿真、逆动力学或动力学积分函数。

### 10.3 端到端验收

1. JOG 到第一个姿态并记录 P1。
2. JOG 到第二个姿态并记录 P2。
3. 创建 `PTP P1 → P2` 五次多项式指令。
4. 修改持续时间并观察速度和加速度峰值按预期变化。
5. 播放 3D，拖动图表游标并核对公式代入同步。
6. 切换梯形速度，观察三段着色和加速度跳变说明。
7. 放大 3D 后继续播放，再恢复三栏布局。
8. 验证轨迹示教页面不出现力矩、能量、功率、惯性矩阵或动力学方程。
9. 验证宽屏、中等宽度和窄屏布局顺序及操作可达性。
10. 导出 CSV 和图表，核对字段、单位和文件内容。

## 11. 完成标准

- 用户能完成“JOG → 记录 P1/P2 → 创建 PTP → 生成预览 → 试运行”的完整流程。
- 五次多项式和梯形速度两类轨迹均有公式、曲线和 3D 同步教学。
- 大尺寸 3D 是桌面布局的主视觉，默认约占顶部工作区一半宽度，并可独立放大。
- 页面只处理运动学轨迹，不依赖动力学积分或力矩样本。
- 数学核心、组件、端到端测试通过，类型检查和生产构建通过。
- README、数学说明和符号表更新为新的“轨迹示教”定位，不把它描述为动力学实验。
