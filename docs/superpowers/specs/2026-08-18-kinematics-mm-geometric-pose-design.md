# 运动学毫米制、几何法与末端姿态设计

## 目标

在不改变动力学核心 SI 制和内部弧度计算的前提下，改进运动学教学界面：所有面向用户的长度采用毫米，关节角只以度显示，补充可逐步理解的解析几何法推导，并把末端位置与姿态明确区分和共同展示。

## 单位边界

- `RobotParameters`、正逆运动学、动力学、轨迹与场景继续使用米和弧度，避免破坏质量、惯量、重力与力矩的一致性。
- 运动学和机器人模型界面的几何长度输入、D–H 表、目标坐标、位置结果及推导数值显示为毫米；进入状态层前除以 `1000`，从状态层显示前乘以 `1000`。
- 数值齐次变换的旋转块保持无量纲，仅前三行第四列转换为毫米。
- 以度为关节变量展示位置雅可比时，线速度块使用 `1000π/180` 的比例转换为 `mm/°`；角速度块保持无量纲。奇异值同步使用 `mm/°`，条件数不变。

## 角度与姿态

- 删除运动学界面的度/弧度切换，所有关节输入、逆解和推导结果只显示度。
- 内部三角函数仍使用弧度，但不在教学界面暴露转换步骤或 `rad` 标签。
- D–H 扭角 `α₁` 显示为 `90°`。
- 末端姿态展示为旋转矩阵 `⁰R₃`，并显示机构自然参数：基座方位角 `θ₁` 与末端连杆仰角 `β=θ₂+θ₃`。
- 末端坐标系与第三连杆坐标系重合，即 `{e}≡{3}`。本次只展示实际姿态，不增加任意六维目标姿态输入，因为偏航–俯仰–俯仰 3R 机构无法独立满足任意位置和方向。

## 几何法推导

逆运动学过程按几何意义拆开：

1. 将目标投影到竖直工作平面，计算 `r=√(x²+y²)`、`h=z-d₁` 和肩部到目标距离 `s=√(r²+h²)`。
2. 由水平投影计算 `θ₁=atan2(y,x)`。
3. 使用余弦定理计算 `D` 与 `θ₃=±acos(D)`。
4. 定义目标方向角 `γ=atan2(h,rₛ)` 和三角形补偿角 `δ=atan2(l₃sinθ₃,l₂+l₃cosθ₃)`，得到 `θ₂=γ−δ`。
5. 对折叠径向族明确使用 `rₛ=-r`、`θ₁=atan2(y,x)+180°`，使展示公式与实际求解分支一致。
6. 将每组解析解代回正运动学，显示位置回代误差和对应末端姿态。

“肘上/肘下”称为构型，不再称为末端姿态；同时显示 `θ₃` 正负号和径向族，避免构型标签在折叠解中产生歧义。

## 测试

- 组件测试验证角度界面不再出现弧度切换、目标坐标使用毫米且正确换算、逆解只显示度。
- 推导模型测试验证毫米显示矩阵只缩放平移列、姿态矩阵为正确的 `3×3` 旋转块、回代误差接近零、折叠径向族的几何中间量与实际解一致。
- 页面测试验证新增几何步骤、姿态结果和 D–H 毫米/角度表。
- 完整运行单元测试、类型检查、生产构建与浏览器验收。
