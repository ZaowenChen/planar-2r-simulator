# 平面 2R 机械臂正运动学仿真器设计

## 目标

用 Python、NumPy 和 Matplotlib 实现一个单文件、可直接运行的平面 2R 机械臂正运动学仿真器。用户通过两个角度滑块观察机械臂姿态、各局部坐标系、末端坐标和总齐次变换矩阵的实时变化。

默认连杆长度为 `L1 = 2.0`、`L2 = 1.5`，初始角度为 `theta1 = 30°`、`theta2 = 45°`。

## 架构

采用“函数式数学核心 + GUI 类”的单文件结构：

- `dh_transform(theta, a, alpha, d)`：纯函数，返回标准 D-H 单连杆齐次变换矩阵。
- `forward_kinematics(theta1, theta2, l1, l2)`：纯函数，计算两级变换与三个坐标原点。
- `Planar2RSimulator`：负责创建 Matplotlib 界面、保存图形对象、响应滑块事件并刷新显示。
- `main()`：创建仿真器并启动 Matplotlib 事件循环。

数学核心不依赖 GUI 状态，因此可以独立测试；GUI 类只负责显示与交互。

## D-H 模型与正运动学

使用标准 D-H 变换：

```text
T(theta, a, alpha, d) =
[[cos(theta), -sin(theta)cos(alpha),  sin(theta)sin(alpha), a cos(theta)],
 [sin(theta),  cos(theta)cos(alpha), -cos(theta)sin(alpha), a sin(theta)],
 [0,           sin(alpha),            cos(alpha),           d           ],
 [0,           0,                     0,                    1           ]]
```

平面 2R 机械臂的参数为：

| 变换 | theta | a | alpha | d |
| --- | --- | --- | --- | --- |
| `T01` | `theta1` | `L1` | `0` | `0` |
| `T12` | `theta2` | `L2` | `0` | `0` |

计算关系：

- `T01 = dh_transform(theta1, L1, 0, 0)`
- `T12 = dh_transform(theta2, L2, 0, 0)`
- `T02 = T01 @ T12`
- `O0 = (0, 0)`
- `O1` 取 `T01` 平移列的前两个元素
- `O2` 取 `T02` 平移列的前两个元素

`forward_kinematics` 返回 `T01`、`T12`、`T02` 和 `O0/O1/O2`。所有数学函数使用弧度；滑块显示的角度在进入数学核心前由度转换为弧度。

局部坐标系方向由累计变换的旋转部分获得：`O0` 使用单位矩阵，`O1` 使用 `T01[:2, :2]`，`O2` 使用 `T02[:2, :2]`。每个坐标系的 X 轴为红色，Y 轴为绿色。

## 图形界面

窗口分为三个区域：

- 左侧主绘图区：机械臂连杆、关节节点、局部坐标轴、网格和工作空间边界。
- 右侧信息区：实时显示末端坐标与格式化后的 `4×4` 矩阵 `T02`。
- 底部控制区：两个 `matplotlib.widgets.Slider`，范围均为 `[-180°, 180°]`。

绘图区保持等比例坐标。坐标范围根据 `L1 + L2` 自动设置并留出边距。以基座为圆心绘制半径 `L1 + L2` 的外边界圆和半径 `abs(L1 - L2)` 的内边界圆；两者使用不抢占主体视觉的虚线。

机械臂用一条折线连接 `O0 → O1 → O2`，节点使用圆点。坐标轴长度与总臂长成比例，确保不同连杆参数下仍清晰可见。图例区分机械臂、工作空间边界和局部坐标轴颜色。

## 交互数据流

1. GUI 初始化时按默认角度调用正运动学函数。
2. 创建机械臂线条、节点、六条局部坐标轴线、文本对象和滑块。
3. 任一滑块变化时，回调读取两个角度并转换为弧度。
4. 回调重新计算 `T01`、`T12`、`T02` 和三个原点。
5. 原位更新现有 Matplotlib artist 的数据，避免反复清空或重建坐标轴。
6. 更新末端坐标文本与矩阵文本，再调用 `draw_idle()` 请求重绘。

## 输入验证与错误处理

- `L1`、`L2` 必须是有限正数；否则抛出说明明确的 `ValueError`。
- 角度由滑块提供有限范围值，数学函数保持纯数值接口。
- 矩阵文本使用固定精度和抑制微小科学计数法的格式，避免浮点噪声影响阅读。

## 测试与验收

开发阶段使用标准库 `unittest` 编写独立测试，不增加运行依赖。测试先于生产代码编写，并覆盖：

- D-H 变换在零角度和平面参数下的矩阵结构。
- `T02` 等于 `T01 @ T12`。
- `theta1=0°`、`theta2=0°` 时末端为 `(3.5, 0)`。
- `theta1=90°`、`theta2=0°` 时末端为 `(0, 3.5)`。
- `theta1=0°`、`theta2=180°` 时末端为 `(0.5, 0)`。
- 非法连杆长度被拒绝。
- Matplotlib 无界面后端下可实例化 GUI、改变滑块并刷新图形。

最终验收包括：运行单元测试、Python 语法编译检查、无界面渲染并保存一张预览图，以及人工检查预览图中的机械臂、坐标轴、工作空间边界和信息区是否完整。

## 交付物

- `planar_2r_simulator.py`：用户可直接运行的单文件仿真器，仅依赖 NumPy 和 Matplotlib。
- `test_planar_2r_simulator.py`：开发验证测试，使用 Python 标准库 `unittest`。

运行方式：

```bash
python planar_2r_simulator.py
```
